# An indented line is not judged as a delimiter

The line is not a delimiter line, so the two lines are not a table
candidate, and the pipeless header is not ambiguous.

docs/adjudications/0005-closing-draft-0s-gaps.md, item 2:

> **2. A table's delimiter line** indented four or more columns is not a
