# A lone pipe followed by a tab ends the table

docs/adjudications/0005-closing-draft-0s-gaps.md, item 3:

> A non-blank line directly below a table's rows is another row when it
> holds an unescaped pipe, starts no other block, and is not only `|` with
> spaces or tabs around it.

So the line is not a row, and is a non-blank line directly below the table.
