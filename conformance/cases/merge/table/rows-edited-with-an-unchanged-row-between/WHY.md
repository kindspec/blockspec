# Each branch edits a different row of a table

An unchanged row keeps the edits apart, so stock git merges them. The table is
one opaque leaf with the merged rows.

SPEC.md §4.3:

> **A table must have a blank line, or its container's edge, on both sides**

SPEC.md §4.3, on what a table is:

> **GFM pipe tables are in the profile, as a leaf block**
