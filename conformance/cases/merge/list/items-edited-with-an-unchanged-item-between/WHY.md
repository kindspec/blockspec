# Each branch edits a different item of a list

One item between the edits keeps them apart. A list is one block (§6.1) but its
lines merge separately. The merged list holds every item, once each.

0002 §1 is the partition rule this case relies on (SPEC.md §6.1):

> **A block is a top-level node.** A document is a sequence of blocks. A list
> is one block, and so are a block quote and a table.
