# An earlier copy of the span inserted before the context

The inserted text holds the span's words but not its context, so the one hit
is the original occurrence, and the text before it is read from the current
leaf.

docs/adjudications/0005-closing-draft-0s-gaps.md, item 9:

> The content before the span is read from the leaf the anchor is paired
> with in the current document, not from the record's stored base text.
