# No transclusion: an image titled `transclude`

The paragraph is one image, not one link.

SPEC.md §11.9:

> **A transclusion is a paragraph whose content is exactly one inline link
> with the title `transclude`** (0003 Q5)

CommonMark 0.31.2, *Images*:

> Syntax for images is like the syntax for links, with one
> difference. Instead of [link text], we have an
> [image description](@).
