# A delimiter line indented by a tab

Item 2 counts columns, and a tab at the start of a line advances to column
four (SPEC.md §3).

docs/adjudications/0005-closing-draft-0s-gaps.md, item 2:

> **2. A table's delimiter line** indented four or more columns is not a
> delimiter line. It continues the paragraph above.

SPEC.md, §3:

> a tab advances to the next multiple of four columns wherever spaces
> define block structure.
