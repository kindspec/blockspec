# A table below a closing line with trailing spaces

A closing line may carry trailing spaces, and it is an edge all the same.

docs/adjudications/0005-closing-draft-0s-gaps.md, item 4:

> **4. Frontmatter's closing line is an edge.** A table directly below
> it has its container's edge above it, and is not
> `table-not-blank-above`.

SPEC.md, §5:

> **It is closed by a line of `---` followed only by spaces or tabs**
